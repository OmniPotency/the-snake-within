# The Snake Within

**Relic #3 — part of "The Relic of Who I Was"**

A modern reimagining of the classic Snake game — built from scratch in C++ using the SFML 3.x graphics library, with full object-oriented architecture behind it.


## Features
- Two wall modes: Classic (die on wall) and Wrap-Around (Nokia-style)
- Four snake color themes and four fruit types, selectable before each game
- Difficulty that scales with score — the snake gets faster as you play
- Full menu flow: main menu → setup screens → ready screen → gameplay → pause → game over
- Session high score tracking

## 📄 Documentation
This project includes a complete **Software Requirements Specification (SRS)** — covering functional and non-functional requirements, use cases, UML class design, SDLC model, risk management, and full test cases. Built as a proper engineering document, not just a code dump.

## Files
- `main.cpp`, `Snake.cpp`, `Snake.h` — full source code
- `arial.ttf`, `libsfml-*.dll` — required runtime assets
- `SnakeGame_Manual.docx` — build/run guide
- `THE_SNAKE_WITHIN.pdf` — full SRS document

## 🛠️ Requirements
- Windows, C++17+, SFML 3.x
- Keep the `.exe` (built by you), DLLs, and `arial.ttf` in the same folder to run
